# Computer Networks Laboratory (CN Lab)

Repository containing C programs, packet analysis documentation, and lab records for the Computer Networks Laboratory course.

---

## Laboratory Experiments Directory

| Exp No. | Experiment Name |
| :---: | :--- |
| **1** | Study of Basic & Advanced Network Commands (`ping`, `ipconfig`, `tracert`, `netstat`, `nslookup`) |
| **2** | Count the number of comments, keywords, identifiers, words, lines and spaces from input file |
| **3** | Socket Programming for Transport Layer Packets (TCP Server) |
| **4** | Socket Programming for Transport Layer Packets (TCP Client) |
| **5** | Socket Programming for Transport Layer Protocol (UDP Client/Server) |
| **6** | Analysis of Application Layer Packets (DNS) Using Commands and Wireshark |
| **7** | Analysis of Application Layer Packets (DNS & HTTP) Using Wireshark |
| **8** | Implementation of Sliding Window Protocol Using Go-Back-N ARQ Technique |
| **9A**| Implementation of Traffic Shaping Algorithm Using the Leaky Bucket Technique |
| **9B**| Implementation of Traffic Shaping Algorithm Using the Token Bucket Technique |
| **10**| Implementation of Distance Vector Routing Algorithm |

---

## Instructions for Execution

### 1. Compiling & Running C Programs
Navigate to any specific experiment folder containing a `.c` file and run:
```bash
gcc filename_1221.c -o program_output
./program_output
```
